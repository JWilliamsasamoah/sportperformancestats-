HOW IT WORKS
Get a game up and running in under 2 minutes.
01
👥

Set Up Teams

Go to the Teams page. Add your teams and build each roster with player names and jersey numbers.

02

Create a Game

Head to the Lobby. Pick the home and away teams, hit Create Game, and get a unique 6-character room code.

03

Track Live Stats

On the Scoreboard, tap a player to select them, then hit any stat button — +2, +3, FT, REB, AST and more.

04
📲

Share Coach Links

Tap Coach Links in the nav. Each coach gets a personal link with a live read-only view of their team.

05

What You Get
FULL FEATURE SET
Everything you need to run professional-level game tracking.
🏀

Live Scoreboard

Real-time score, game clock, period tracker, fouls and timeouts for both teams. Undo any stat instantly.

📲

Coach View

Shareable read-only link for each coach. Shows live roster, player stats, charts and play log — no login needed.

📊

Box Score

Full per-player stat table with PTS, FT, AST, REB, BLK, STL, TOV, PF, 2PT%, 3PT% and FT%. Sortable and searchable.

Charts & Analytics

Score breakdown, shooting efficiency, shot volume, player comparisons, radar charts and top performer leaderboards.

Player Profiles

Season-aggregated stats for every player. Game history, per-game trend line, scoring split and play-by-play timeline.

Export to Excel

Download the full box score as an XLSX file at any point. Separate sheets for home and away teams.
